# Помощник рентгенолога

Набираете, что описываете, — получаете шаблон заключения, чек-лист «Что проверить» и нужные классификации. КТ, рентген, маммография. Для врачей и ординаторов.

Где что лежит:
- `templates/` — шаблоны заключений
- `ru/` — разделы-подсказки: классификации, пороги, чек-листы
- `index.html` — код сайта

Что сделано и что задумано — в [CHANGELOG.md](CHANGELOG.md).

## Как поправить раздел

1. Откройте нужный файл в `ru/`, например `ru/bosniak.md`.
2. Нажмите карандаш (Edit), внесите правку, нажмите **Commit changes**.
3. Через 1–2 минуты правка появится на сайте.

## Как добавить раздел

1. В папке `ru/`: **Add file → Create new file**, имя латиницей без пробелов, например `lirads.md`.
2. Добавьте имя файла строкой в `ru/order.txt` — в том месте, где раздел должен стоять.

Шапка с датой сверки и ответственным — в `ru/about.md`. Сейчас она скрыта: в `ru/order.txt` перед `about.md` стоит `#`. Уберите решётку, чтобы показать.

## Шаблоны заключений

На главной только строка «Что описываем?». Набираете «огк», «бца», «колено» — сайт показывает шаблон с кнопкой «Скопировать», а под ним подсказки из `ru/`.

Шаблоны лежат в папке `templates/`, один файл — один вариант исследования:

```
Исследование: КТ органов грудной клетки   ← одинаковое у всех вариантов одного исследования
Вариант: Без контраста                     ← название вкладки
Модальность: КТ                            ← КТ, Рентген, ММГ
Слова: огк, грудная клетка, лёгкие         ← по ним ищется, пишите все синонимы
Подсказки: fleischner, lungrads            ← имена файлов из ru/ без .md
---
Дальше текст шаблона как есть, с любыми переносами строк.
Именно он копируется кнопкой.
```

- Строка `---` обязательна: всё, что выше, — служебное, всё, что ниже, — шаблон.
- Поля для заполнения пишите в квадратных скобках: `[правой]`, `[__] мм`.
- Чтобы добавить шаблон: **Add file → Create new file** в папке `templates/`, имя латиницей, и строкой в `templates/order.txt`.
- Варианты одного исследования показываются вкладками в порядке `templates/order.txt`.
- Никаких ФИО, дат и номеров исследований: сайт публичный.

## Переключатели, поля и калькуляторы в шаблонах

Прямо в тексте шаблона, после строки `---`:

```
Кальциноз стенки {умеренный|минимальный|выраженный}.   ← переключатель: тап листает варианты
Стеноз устья {правой|левой} ВСА.                       ← первый вариант стоит по умолчанию
Протяжённость бляшки [__] мм.                          ← пустое поле: вбить число
Рентгенография [правого] коленного сустава.            ← поле с текстом по умолчанию
Минимальный просвет [Dмин] мм, дистальная ВСА [Dдист] мм.   ← поля для калькулятора
Стеноз {{NASCET}}% по NASCET.                          ← считается само
```

- **Одинаковые переключатели связаны.** Если `{правой|левой}` стоит и в описании, и в заключении, тап по одному меняет оба. Варианты должны совпадать буква в букву.
- **Пустой вариант** убирает фразу: `{|Единичные кальцинаты до 3 мм.}` — по умолчанию фразы нет, тап добавляет.
- **Именованные переключатели** связывают описание и заключение разными словами. Все `{#сердце: ...}` переключаются вместе, по номеру варианта:
  ```
  {#сердце: Тень сердца обычной конфигурации.|Тень сердца расширена, КТИ [__]%.}
  ...
  ЗАКЛЮЧЕНИЕ: ... {#сердце: |Кардиомегалия.}
  ```
  Пустой вариант показывается на сайте как «+ сердце» — по имени понятно, что включится. Строка, где остался только пустой вариант, при копировании исчезает целиком.
- **Поле и калькулятор внутри переключателя можно:** `{|Перелом [__] ребра [справа].}`, `{#сердце: Тень сердца обычной конфигурации.|Тень сердца расширена, КТИ {{КТИ}}% (сердце [Сердце] мм, грудная клетка [Грудь] мм).}`. А вот переключатель внутри переключателя — нельзя.
- **Незаполненное поле** копируется как `[__]`, чтобы его было видно в РМ.
- **Кнопка «Сбросить»** возвращает шаблон в исходный вид.

Калькуляторы и их поля:

| Калькулятор | Поля | Что считает |
|---|---|---|
| `{{NASCET}}` | `[Dмин]` `[Dдист]` | Стеноз ВСА по NASCET, % |
| `{{ECST}}` | `[Dмин]` `[Dлук]` | Стеноз ВСА по ECST, % |
| `{{ОБЪЁМ}}` | `[Длина]` `[Ширина]` `[Высота]` | Объём эллипсоида, мл (размеры в мм) |
| `{{КТИ}}` | `[Сердце]` `[Грудь]` | Кардиоторакальный индекс, % (единицы любые, но одинаковые) |
| `{{ЭВАНС}}` | `[Рога]` `[Череп]` | Индекс Эванса: макс. ширина передних рогов / макс. внутренний поперечник черепа (> 0,3 — вентрикуломегалия) |

Новый калькулятор добавляется в `index.html` в список `CALC` — там же есть образец.

## Как оформлять текст

```
# Название раздела               ← первая строка, одна решётка и пробел
> Для чего и когда применять      ← строка-пояснение под названием

## Подзаголовок                   ← две решётки

Обычный абзац. **Жирный текст** — двумя звёздочками с каждой стороны.

- пункт списка                    ← дефис и пробел
- ещё пункт

`Формула = (А − Б) / А × 100%`     ← строка целиком в обратных кавычках

| Колонка 1 | Колонка 2 |         ← таблица: первая строка — заголовки
|---|---|                          ← обязательная строка-разделитель
| ячейка | ячейка<br>вторая строка ячейки |

Источник: Автор, журнал, год. [ссылка](https://...)
Radiopaedia: [Название статьи](https://radiopaedia.org/articles/...)
```

Ссылку на Radiopaedia берите из адресной строки открытой статьи. Если статьи нет, можно дать ссылку на поиск: `https://radiopaedia.org/search?scope=articles&q=запрос+через+плюс`.

## Таблицы: три правила, чтобы не развалить

1. **Одна строка таблицы — одна строка в файле.** Не нажимайте Enter внутри ячейки. Перенос внутри ячейки — `<br>`.
2. **В каждой строке столько же вертикальных черт `|`, сколько в заголовке.** Пустая ячейка — просто `| |`.
3. **Символ `|` внутри текста ячейки не используйте** — он считается границей колонки.

Пропущенная черта или лишний Enter дают кривую таблицу, а не ошибку. После правки откройте раздел на телефоне и проверьте глазами.

## Проверка перед правкой порогов

Любая цифра здесь кто-то потом впишет в заключение. Меняя порог, сверяйтесь с первоисточником и обновляйте дату в `ru/about.md`.

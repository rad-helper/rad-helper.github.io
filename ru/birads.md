# BI-RADS — маммография

> Итоговая категория маммографического заключения и тип плотности ткани по ACR (5-е издание атласа).

## Категории

| Категория | Значение | Тактика |
|---|---|---|
| 0 | Оценка неполная | Дополнительные проекции, УЗИ или сравнение с прежними снимками |
| 1 | Норма | Плановый скрининг |
| 2 | Доброкачественные изменения | Плановый скрининг |
| 3 | Вероятно доброкачественные (риск рака ≤ 2%) | Контроль через 6 мес |
| 4 | Подозрение на злокачественность (> 2 до < 95%) | Биопсия. Подкатегории 4A, 4B, 4C — по нарастанию риска |
| 5 | Высоко вероятная злокачественность (≥ 95%) | Биопсия |
| 6 | Рак, подтверждённый биопсией | Лечение |

## Тип плотности ткани по ACR

| Тип | Описание |
|---|---|
| A | Почти полностью жировая ткань |
| B | Отдельные участки фиброгландулярной ткани |
| C | Неоднородно плотная ткань, может скрывать небольшие образования |
| D | Очень плотная ткань, чувствительность маммографии снижена |

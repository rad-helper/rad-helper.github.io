# BI-RADS — категории и плотность

> Итоговая категория маммографического заключения и плотность ткани по ACR. Действующая версия — BI-RADS v2025 (декабрь 2025), продолжение 5-го издания: категории 1–5 не менялись.

## Категории

| Категория | Значение | Тактика |
|---|---|---|
| 0 | Оценка неполная. С v2025 указывают причину: нужно дообследование **или** нужны прежние снимки для сравнения | Дополнительные проекции, УЗИ — или запросить прежние маммограммы |
| 1 | Норма | Плановый скрининг |
| 2 | Доброкачественные изменения | Плановый скрининг |
| 3 | Вероятно доброкачественные (риск рака ≤ 2%) | Контроль: 6 мес — сторона находки, затем 12 и 24 мес — обе железы |
| 4A | Низкое подозрение (> 2 до ≤ 10%) | Биопсия |
| 4B | Умеренное подозрение (> 10 до ≤ 50%) | Биопсия |
| 4C | Высокое подозрение (> 50 до < 95%) | Биопсия |
| 5 | Высоко вероятная злокачественность (≥ 95%) | Биопсия |
| 6 | Рак, подтверждённый биопсией, до окончания лечения | Ведение хирургом и онкологом; в v2025 лечение не обязательно хирургическое |

- **Категория 6 в v2025** распространяется и на соседние подозрительные находки: в пределах 2 см от подтверждённого рака, не увеличивающие протяжённость поражения больше чем на 2 см и не меняющие тактику.
- **Обе железы с разными категориями:** можно указать категорию для каждой; итоговая — более подозрительная.

## Когда можно ставить 3

- Только после диагностического обследования. По скрининговому снимку находка требует дообследования — это 0, а не 3.
- Маммографически подходят три находки: образование с чёткими контурами без кальцинатов, фокальная асимметрия, одна группа округлых кальцинатов.
- Увеличение при контроле — повод для биопсии.

## Примеры категории 2

- Обызвествлённая фиброаденома; жировая киста, липома, гамартома; интрамаммарный лимфоузел с жировыми воротами
- Сосудистые и другие типично доброкачественные кальцинаты
- Импланты; рубец после операции без отрицательной динамики
- Множественные расширенные протоки (v2025)

Доброкачественную находку можно не описывать — тогда категория 1. Описали — ставьте 2.

## Плотность ткани по ACR

| Тип | Описание |
|---|---|
| A | Почти полностью жировая ткань |
| B | Разрозненные участки фиброгландулярной плотности |
| C | Неоднородно плотная ткань, может скрывать небольшие образования |
| D | Очень плотная ткань, чувствительность маммографии снижена |

- В v2025 раздел называется «плотность», а не «состав», и идёт отдельным пунктом протокола.
- Тип ставят по самому плотному участку: важно, может ли ткань скрыть образование, а не средний процент. Железы разной плотности — по более плотной.
- C и D снижают чувствительность маммографии — это стоит отразить в заключении.

## Порядок протокола в v2025

Показания → сравнение с прежними снимками → методика → плотность → находки → категория → рекомендации.

## После лечения

После мастэктомии оставшуюся железу оценивают обычными категориями 1–5. Категория 6 — только для подтверждённого рака до завершения лечения.

# Стеноз внутренней сонной артерии — NASCET

> КТ-ангиография; процент стеноза по диаметру.

`Стеноз = (1 − Dмин / Dдист) × 100%`

- **Dмин** — наименьший диаметр просвета в зоне стеноза (поперечный срез, перпендикулярно оси сосуда)
- **Dдист** — диаметр нормальной ВСА дистальнее луковицы, где стенки становятся параллельными

| Степень | Комментарий |
|---|---|
| < 50% | Незначимый |
| 50–69% | Умеренный |
| 70–99% | Выраженный |
| Субокклюзия | Дистальная ВСА спадается («симптом струны»): формула занижает стеноз, процент не считают — так и пишут: субокклюзия |
| Окклюзия | Нет контрастирования просвета |

Источник: NASCET Collaborators. N Engl J Med 1991;325:445–453. [Калькулятор и пояснения](https://radathand.com/radiology-calculators/neuroradiology/nascet-calculator/)

Находка: Узел в лёгком
Модальность: КТ
Слова: узел узелок узла узлы очаг очаги легкое легкого легких fleischner флейшнер матовое стекло субсолидный солидный частично находка
Подсказки: fleischner
---
> Fleischner 2017: случайный узел у взрослого ≥ 35 лет. Размер — среднее длинной и короткой осей, округлить до целого мм; тонкие срезы, лёгочное окно.

# Параметры
excl: Ситуация = случайная находка, ≥ 35 лет | скрининг рака лёгкого | иммуносупрессия | известный онкопроцесс
benign: Доброкачественные признаки = нет | доброкачественное обызвествление | жир (гамартома) | перифиссуральный (внутрилёгочный лимфоузел)
type: Тип = солидный | «матовое стекло» | частично солидный ; если benign = нет
num: Количество = одиночный | множественные ; если benign = нет
size: Размер, мм = число ; если benign = нет
solid: Солидный компонент, мм = число ; если benign = нет и type = частично солидный
risk: Риск = низкий | высокий ; если benign = нет и type = солидный

# Вывод
- excl = скрининг рака лёгкого → **Fleischner не применяется** — для скрининга есть Lung-RADS.
- excl = иммуносупрессия или excl = известный онкопроцесс → **Fleischner не применяется** — тактика индивидуально, с лечащим врачом.
- benign = доброкачественное обызвествление → **Доброкачественное обызвествление** (диффузное, центральное, слоистое, «попкорн»). Контроль не нужен.
- benign = жир (гамартома) → **Жир в узле — гамартома.** Контроль не нужен.
- benign = перифиссуральный (внутрилёгочный лимфоузел) → **Перифиссуральный узел типичной формы** (треугольный или линзовидный, у щели или плевры) — внутрилёгочный лимфоузел. Контроль не нужен, даже если > 6 мм.
- type = солидный и size < 6 и risk = низкий → **Солидный < 6 мм, низкий риск.** Контроль не нужен.
- type = солидный и size < 6 → **Солидный < 6 мм, высокий риск.** КТ через 12 месяцев — по желанию.
- type = солидный и size <= 8 и num = одиночный и risk = низкий → **Солидный 6–8 мм, одиночный, низкий риск.** КТ через 6–12 месяцев, затем рассмотреть КТ через 18–24 месяца.
- type = солидный и size <= 8 и num = одиночный → **Солидный 6–8 мм, одиночный, высокий риск.** КТ через 6–12 месяцев, затем через 18–24 месяца.
- type = солидный и size <= 8 и risk = низкий → **Солидные 6–8 мм, множественные, низкий риск.** КТ через 3–6 месяцев, затем рассмотреть КТ через 18–24 месяца.
- type = солидный и size <= 8 → **Солидные 6–8 мм, множественные, высокий риск.** КТ через 3–6 месяцев, затем через 18–24 месяца.
- type = солидный и size > 8 и num = одиночный → **Солидный > 8 мм.** Рассмотреть КТ через 3 месяца, ПЭТ/КТ или биопсию.
- type = солидный и size > 8 и risk = низкий → **Солидные > 8 мм, множественные, низкий риск.** КТ через 3–6 месяцев, затем рассмотреть КТ через 18–24 месяца.
- type = солидный и size > 8 → **Солидные > 8 мм, множественные, высокий риск.** КТ через 3–6 месяцев, затем через 18–24 месяца.
- type = «матовое стекло» и num = одиночный и size < 6 → **«Матовое стекло» < 6 мм.** Контроль не нужен.
- type = «матовое стекло» и num = одиночный и size >= 6 → **«Матовое стекло» ≥ 6 мм.** КТ через 6–12 месяцев — подтвердить, что не исчез; затем каждые 2 года до 5 лет.
- type = частично солидный и num = одиночный и size < 6 → **Частично солидный < 6 мм.** Контроль не нужен.
- type = частично солидный и num = одиночный и size >= 6 и solid >= 6 → **Частично солидный, солидный компонент ≥ 6 мм — высоко подозрителен.** КТ через 3–6 месяцев; если сохраняется — ПЭТ/КТ, биопсия или резекция.
- type = частично солидный и num = одиночный и size >= 6 → **Частично солидный ≥ 6 мм.** КТ через 3–6 месяцев; если без изменений и солидный компонент < 6 мм — ежегодно 5 лет.
- num = множественные и size < 6 → **Множественные субсолидные < 6 мм.** КТ через 3–6 месяцев; если стабильны — рассмотреть КТ через 2 и 4 года.
- num = множественные и size >= 6 → **Множественные субсолидные, ≥ 6 мм.** КТ через 3–6 месяцев, дальше — по самому подозрительному узлу.
- иначе → Введите размер.

# Учесть
- num = множественные → Тактику определяет самый подозрительный узел, не обязательно самый крупный.
- type = солидный и risk = низкий → Высокий риск: курение, рак лёгкого у родственников, эмфизема или фиброз, верхняя доля, спикулы, контакт с асбестом и др.
- type = частично солидный и solid → Размер — весь узел; солидный компонент меряют отдельно.
- type = частично солидный и size >= 6 и solid = 0 → Солидный компонент 0 — это «матовое стекло», а не частично солидный узел.
- type = «матовое стекло» или type = частично солидный → Субсолидные часто исчезают — поэтому первый контроль подтверждает, что узел вообще остался.
- size >= 30 → ≥ 30 мм — уже не узел, а образование: Fleischner для него не предназначен.
